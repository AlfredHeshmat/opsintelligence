# OpsIntelligence — Resume-ready project entries

Use the **three-bullet version** on a one-page resume. Links below are public and verified as deployed during November 2026. The local enterprise prototype is *not* production-certified or public.

## Recommended: 3 bullets (graduate / full-stack / AI / FDE)

**OpsIntelligence | Full-Stack Operational Intelligence & Decision Optimisation Platform**  
*React, TypeScript, Python, FastAPI, PostgreSQL, SQLAlchemy, SciPy/HiGHS, scikit-learn, Docker, GitHub Actions*  
[Live Demo](https://opsintelligence.pages.dev) | [GitHub](https://github.com/AlfredHeshmat/opsintelligence)

- Engineered and deployed a full-stack operations platform with React/TypeScript, FastAPI REST APIs and PostgreSQL, featuring interactive dashboards, order analytics and a publicly accessible synthetic-data demo.
- Implemented bounded mixed-integer linear programming (MILP) optimisers for warehouse decisions and three industry pilots, plus ML evaluation and Monte Carlo what-if analysis with explicit assumptions and solver-status reporting.
- Built Docker-based environments, Alembic migrations, role-controlled local enterprise prototypes and GitHub Actions CI; validated **64 backend** and **21 frontend** tests, and deployed using Cloudflare Pages, Render and Neon free tiers.

## Suggested interview positioning

**30-second summary:** “I built OpsIntelligence to demonstrate end-to-end engineering, not just dashboards. The public React/FastAPI/PostgreSQL platform lets users explore operational data, change optimisation assumptions, run bounded mathematical models and compare scenarios. I separated the synthetic public demo from the local enterprise identity prototype, tested the backend and frontend, and deployed everything on free cloud tiers. I can explain the solver's objective, data boundaries, deployment and trade-offs.”

**Avoid claiming:** production enterprise deployment; real client cost savings; universal or quadrillion-variable optimisation; proven forecasting accuracy; unrestricted secure multi-tenant SaaS; real-time ingestion unless specifically demonstrated.
